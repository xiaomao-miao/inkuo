# RAG：索引与增量更新

## 1. 目标
- 对 workspace 文档建立可增量更新的向量索引。
- 支持按引用与语义检索召回片段。

## 2. Chunk 策略
- 基于 Document Engine 提供的块级边界（标题/段落/表格/列表）。
- 对过长块进行二次切分（按句子或行）。

## 3. 增量更新
- 触发：保存文件、文件系统变更事件、手动重建。
- 机制：
  - 计算文件 hash
  - 对比 blocks/chunks hash
  - 只更新变化部分

## 4. 检索
- 向量召回 +（可选）关键字过滤。
- 按 token 预算拼装上下文。

## 5. 质量与性能
- 索引在后台进行，不阻塞编辑。
- 提供索引状态 UI（进行中/失败/完成）。
